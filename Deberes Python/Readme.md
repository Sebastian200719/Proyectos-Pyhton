# Comparación entre Programación Tradicional y Programación Orientada a Objetos en Python

## Objetivo
Desarrollar un sistema básico de gestión de mascotas utilizando dos enfoques diferentes: Programación Tradicional y Programación Orientada a Objetos.

## Programación Tradicional
Utiliza funciones y variables para registrar y mostrar la información de una mascota.

## Programación Orientada a Objetos
Utiliza una clase llamada Mascota para representar las características y comportamientos de una mascota mediante objetos.

## Conclusión
La Programación Tradicional es adecuada para programas pequeños, mientras que la Programación Orientada a Objetos permite una mejor organización, reutilización y mantenimiento del código.
