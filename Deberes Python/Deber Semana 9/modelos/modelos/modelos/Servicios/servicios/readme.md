## Descripción

El proyecto restaurante_app es un sistema de administración básica para un
restaurante desarrollado en Python utilizando programación orientada a objetos.

El sistema permite administrar productos y usuarios mediante un menú interactivo
por consola.

En esta Semana 9 se incorporan las principales estructuras de datos de Python:

- list
- tuple
- dict
- set

Cada estructura cumple una función concreta dentro del sistema.
